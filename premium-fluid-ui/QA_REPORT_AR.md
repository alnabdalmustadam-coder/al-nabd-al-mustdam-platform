# Premium Fluid UI v1.4.0 — تقرير الفحص والتحقق الهندسي

## ملخص تحديثات الإصدار v1.4.0

1. **توسيع مصفوفة الشاشات ثنائية الأبعاد (2D Viewport Matrix):**
   - إضافة شاشات **`1024×600` (WSVGA / Compact Landscape)**، والشاشات منخفضة الدقة (`1366×768`، `1280×720`، `800×480`، `360×640`، `320×568`)، والوضع الأفقي للموبايل (`667×375`، `740×360`، `844×390`) والتابلت (`1024×768`، `1180×820`، `960×600`) إلى الفحص السريع (`quick`) والشامل (`full`).
2. **إصلاح الفحص الآلي للـ RTL وكامل ارتفاع الصفحة في `scripts/responsive_audit.py`:**
   - فحص الحافة اليسرى (`rect.left < -3`) والحافة اليمنى (`rect.right > vw + 3`) لجميع العناصر المرئية على **كامل طول الصفحة** بعد إلغاء قيد الجزء العلوي (`r.top < vh`).
   - فحص قص النصوص (`clipped-text-content`) وخروج النصوص عن الشاشة (`text-outside-viewport`) عبر `Range.getClientRects()` وتصنيفها كأخطاء حرجة (`high`).
   - رصد تداخل العناصر العائمة (`position: absolute` و`position: fixed`) مع النصوص والأزرار والتذييل (`floating-or-absolute-overlap`).
   - رصد تكدس الهيدر على الشاشات الصغيرة (`header-crowding-overflow`) واختناق الارتفاع على الشاشات القصيرة (`short-viewport-vertical-crush` و`vertical-overflow-clipped-short-viewport`).
3. **تحديث الفاحص الثابت (`scripts/static_css_audit.py`) وفاحص المكونات (`scripts/component_audit.py`):**
   - خفض عتبة رصد العروض الثابتة إلى `260px`، وإضافة رصد كلاسات Tailwind القياسية (`w-64`, `w-72`, `w-80`, `w-96`)، والشبكات متعددة الأعمدة غير المسبوقة بـ `grid-cols-1` على الموبايل (`grid-cols-2`)، والهوامش السالبة (`-mx-*`)، والتموضع المطلق غير المشروط (`absolute`)، والارتفاع الصارم (`h-screen` / `100vh`).
   - إضافة خيار `--sync-viewport` إلى `component_audit.py` لمزامنة حجم نافذة المتصفح مع عرض الكارت وتفعيل قواعد `@media` أثناء الفحص.
4. **قواعد التحويل الهيكلي الإلزامي (Structural Reflow) في `SKILL.md`:**
   - إلزام الـ Agent بتحويل بنية الهيدر، والبطاقات العائمة، والشبكات، وخطوات العمل عند ضيق العرض أو قصر الارتفاع بدلاً من الاكتفاء بتصغير الأرقام.
