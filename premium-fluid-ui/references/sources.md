# Official / primary reference links

These sources inform principles; the skill's numerical starter tokens are local proposals, not direct official values.

- [Agent Skills specification](https://agentskills.io/specification) — structure/frontmatter/progressive disclosure.
- [Google Antigravity Agent Skills](https://antigravity.google/docs/skills) — project/global skill directories.
- [OpenAI Codex — Build skills](https://developers.openai.com/codex/build-skills) — Codex discovery/invocation and locations.
- [Apple Human Interface Guidelines — Layout](https://developer.apple.com/design/human-interface-guidelines/layout) — adaptable layout and visual hierarchy.
- [Android Adaptive apps — window size classes](https://developer.android.com/develop/adaptive-apps/guides/use-window-size-classes) — available window sizes.
- [MDN — CSS container queries](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Containment/Container_queries) — container sizing and cqi.
- [MDN — CSS values and units](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Values_and_units/Numeric_data_types) — relative, viewport and container length types.
- [W3C WCAG 2.2 Resize text](https://www.w3.org/WAI/WCAG22/Understanding/resize-text.html).
- [W3C WCAG 2.2 Reflow](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html).
- [W3C WCAG 2.2 Target Size (Minimum)](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html).

- [Material Design 3 — Design system](https://m3.material.io/) — use adaptive design, hierarchy and component reasoning; do not copy an unverified number into unrelated brands.
- [Microsoft Fluent 2 — Layout](https://fluent2.microsoft.design/layout) — responsive spacing, grid types, breakpoints as guides rather than hard device rules.
- [Microsoft Fluent 2 — Typography](https://fluent2.microsoft.design/typography/) — semantic roles, readability and coherent type ramps.
- [Microsoft Fluent 2 — Accessibility](https://fluent2.microsoft.design/accessibility) — zoom, responsive reflow, usable focus.
